# ✈️ Airline Passenger Satisfaction Prediction App

A modern **Machine Learning + Streamlit web application** that predicts whether an airline passenger is:

- 😊 **Satisfied**
- 😐 **Neutral**
- 😞 **Not Satisfied**

based on travel details and service ratings.

## 🧠 How It Works

This project uses a **hybrid approach**:

- Machine Learning model trained on airline dataset  
- Rule-based system to improve prediction reliability  

### Logic:

| Average Rating | Output |
|---------------|--------|
| ≥ 4           | 😊 Satisfied |
| 2.5 – 3.5     | 😐 Neutral |
| < 2.5         | 😞 Not Satisfied |
